# Koch Ofenbau – GitHub-Pages-Version

Diese Version besteht nur aus statischem HTML, CSS und Bildern. Sie benötigt weder
WordPress noch Node.js und kann direkt über GitHub Pages veröffentlicht werden.

## Veröffentlichung

1. Den Inhalt dieses Ordners in ein neues GitHub-Repository hochladen.
2. Im Repository **Settings → Pages** öffnen.
3. Unter **Build and deployment** die Option **Deploy from a branch** wählen.
4. Branch **main** und Ordner **/ (root)** auswählen und speichern.
5. Nach kurzer Zeit zeigt GitHub dort die öffentliche Adresse an.

Wichtig: `index.html`, `styles.css` und der Ordner `images` müssen gemeinsam im
Hauptverzeichnis des Repositorys liegen.
